# ito-ZJRY-ppt

复用诸暨市人民医院原生 PPT 模板、医疗图标和文字版式，面向 WPS 编辑与交付。

## 下载和安装

下载仓库根目录的 **[ito-ZJRY-ppt.skill](./ito-ZJRY-ppt.skill)**。它是 ZIP 格式技能包，内含 `ito-zjry-ppt/`。如当前工具支持导入 `.skill`，直接导入；Codex 本地使用时可解压此目录到 `~/.codex/skills/`，并在新会话中使用 `$ito-zjry-ppt`。也可将仓库中的 `ito-zjry-ppt/` 目录直接复制到该位置。

## 使用示例

> 使用 $ito-zjry-ppt 按诸暨市人民医院模板制作护理教学 PPT，复用白底正文与医疗图标，保留可编辑文字和原生组合，交付前在 WPS 中检查。

- 完整原生范本：38 页，1 套母版、25 个版式。
- 验证样例：4 页，包含白底正文、青色图标、反白图标、医院图文页。
- 脚本：Python 3.10+，仅标准库，支持选页、命名文本框替换、对象位置尺寸调整和原生组件提取。
- 字体：本机安装微软雅黑；PPTX 不附带字体文件。
- 基础结构检查不替代 WPS 中的实际显示与可编辑性检查。

## 验证范围

2026-10-20 在 WPS Office 12.1.0.28022 中完成样例改字、移动图标、保存关闭重开及逐页检查。脚本测试通过文字替换、多段正文、独立重复页面、原生组合保留、图标提取、未知对象拒绝及禁止覆盖已有文件。

SmartArt 编辑、图表数据修改、动画、全部版式和跨机器字体替代未验证。技能内明确保留这些边界。

## 源码和校验

源码位于 `ito-zjry-ppt/`。运行 `python ito-zjry-ppt/scripts/test_reuse.py` 检查脚本行为；运行 `python ito-zjry-ppt/scripts/reuse.py --help` 查看命令。技能包校验值见 [SHA256SUMS](./SHA256SUMS)。

`.skill` 文件名保留用户指定大小写，内部技能标识按规范使用 `ito-zjry-ppt`。本仓库不注册为 Template Gallery 的 artifact-template。
