# ito-ZJRY-ppt

优先采用原生 PPTX 资源，保留可编辑文字、图标组合和母版依赖。最终以用户实际使用的 WPS 显示为验收依据。仅讨论或检查时保持只读；调用本 Skill 不授权公开发布、上传或修改其他项目。

## 资源

- `assets/reference.pptx`：完整 38 页范本，1 套母版、25 个版式。保持为只读源。
- `assets/validated.pptx`：4 页经 WPS 实际改字、移动图标、保存并关闭重开检查的样例。
- [模板地图](references/template-map.md)：背景、字号、颜色、元素定位及测试边界。
- `references/catalog.json`：页面及顶层对象索引。索引不代表所有素材均经过单独测试。
- [脚本用法](references/usage.md)：选页、替换文字、提取元素、调整位置尺寸与检查。

## 编辑流程

1. 按内容选择完整页面或原生元素。先看地图和目录；需要确认样式时查看对应源页。不要只根据文件名把所有页面理解为淡色背景。
2. 工作在新副本。常规页面可用 `scripts/reuse.py build` 按 JSON 规格选择页面、重复复制页面、替换命名文本框、移动缩放对象。脚本仅依赖 Python 标准库。
3. 图标保留原生组合，按比例调整组合外层变换；院徽保留原图和比例。以 `--library source` 和 `keep_shapes` 提取源范本组件，随后用可用演示工具复制到目标文件；跨文件复制保留完整依赖，不仅复制一段形状 XML。
4. 新文字显式指定中西文字体为微软雅黑，按页面角色选择字号。正文过多时拆页或调整结构。`texts` 适合统一样式文本框；混合加粗、多种颜色等富文本应逐段编辑。
5. 优先沿用母版、背景、院徽位置和页码变体。HTML 仅作可选预览目录，不作为必经中转格式。
6. 运行 `scripts/reuse.py validate output.pptx`，在 WPS 中逐页检查换行、溢出、图标、图片、院徽、页码和可编辑性。关键修改保存、关闭重开；没有 WPS 时明确报告未完成实际软件验证。

脚本不会自动清空未指定的示例文字。交付前清理测试说明、占位内容、旧日期、旧署名和不需要的素材页。

## 边界

已验证：白底正文、青绿色背景、医师/护理/记录图标的青色及反白变体、医院全景图文组合。尚未验证：全部 25 个版式、SmartArt 重新编辑、图表数据修改、动画、跨机器字体替代。按具体任务验证相关对象。

文件名、位置、页数和内容服从当前请求。不绑定本机绝对路径、其他项目或护理仿真审核入口。
